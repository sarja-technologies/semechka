# Configuration reference

Generated by `scripts/gen_docs.py` from `backend/semechka/settings_reg.py`. Every setting below has a control in Admin → Settings (searchable), the same validation over the API (`PUT /api/admin/settings/{id}`), audit and rollback.

Merge rules when a value is set at several scopes: **specific** = the most specific scope wins (user > team > role > deployment); **false_wins** = any *off* wins, and a deployment-level off is a ceiling; **min** = lowest limit; **min_nonzero** = lowest non-zero (0 = unlimited); **min_nonneg** = shortest retention (-1 = forever).
